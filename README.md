## 📋 Descripción

Aplicación web frontend de EcoTech, plataforma diseñada para promover el reciclaje responsable a través de una experiencia de usuario intuitiva, gamificada y atractiva. Desarrollada con Angular y Material Design siguiendo las mejores prácticas de desarrollo frontend moderno.

### ✨ Características Principales

- 🎨 **Interfaz Moderna**: Diseño responsivo con Angular Material y componentes reutilizables
- 🔐 **Autenticación Segura**: Login/Registro con JWT y guards de protección de rutas
- 👤 **Gestión de Perfil**: Edición completa de datos y cambio de contraseña
- 💎 **Suscripciones Interactivas**: Planes visuales con comparación de beneficios
- ♻️ **Registro de Reciclaje**: Formularios intuitivos con preview de imágenes
- 📊 **Dashboard Personal**: Visualización de puntos, historial y estadísticas
- 🎪 **Eventos Comunitarios**: Calendario de eventos con inscripción en tiempo real
- 🎁 **Tienda de Recompensas**: Catálogo filtrable y ordenable de productos canjeables
- 🔔 **Notificaciones en Tiempo Real**: Sistema de alertas con contador
- 💬 **Sistema de Feedback**: Valoración de eventos con estrellas y comentarios
- 📱 **Diseño Responsivo**: Optimizado para desktop, tablet y móvil

## 🛠️ Stack Tecnológico

- **Framework**: Angular 15+
- **Lenguaje**: TypeScript 5.0
- **UI Components**: Angular Material 15+
- **Gestión de Estado**: RxJS + Observables
- **Routing**: Angular Router con Guards
- **Formularios**: Reactive Forms con validaciones
- **HTTP Client**: Angular HttpClient con interceptores
- **Estilos**: CSS3 + Material Theme
- **Iconos**: Material Icons + Lucide Icons
